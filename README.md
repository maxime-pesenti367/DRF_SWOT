# DRF_SWOT_project

This repository contains two related components for my UCL Masters project.

## Structure

    DRF_SWOT_project/
    ├── DeepRandomFeatures/     # Modified fork of external code (see below)
    └── SWOT experiments/       # My own experiments and analysis

## DeepRandomFeatures

The code in `DeepRandomFeatures/` originates from [totony4real/DeepRandomFeatures](https://github.com/totony4real/DeepRandomFeatures), a PhD student's research repository. It has been lightly modified for the purposes of this project.

## SWOT experiments

The code and notebooks in `SWOT experiments/` are my own work, built on top of the DeepRandomFeatures code above, for my UCL Masters project.

## Data

Data folders are excluded from this repository via `.gitignore` and are not tracked in version control.
